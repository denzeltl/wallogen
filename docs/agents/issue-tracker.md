# Local Markdown Issue Tracker

Issues for this repository live as Markdown files under `.scratch/<feature>/` in the working tree.

## Creating an Issue

To create an issue:
1. Write a markdown file under `.scratch/<feature>/<name>.md`.
2. Include a clear title heading (`# <Title>`) and describe the decision, task, or question.

## Reading and Querying Issues

- Open issues are found by inspecting markdown files inside `.scratch/*/*.md`.
- Closed issues are indicated by moving or archiving the corresponding file or recording resolution in `MILESTONES.md`.
